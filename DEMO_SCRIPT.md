# EngageAI — Live Demonstration Script

## 1. Problem
Faculty may have many indicators of engagement but limited time to identify students
whose participation is declining.

## 2. Solution
EngageAI combines classroom indicators, ML-based risk prediction and conversational
support.

## 3. Dashboard
Show total students, risk distribution and students requiring attention.

## 4. Prediction
Select a student and run prediction. Explain:
- risk class
- confidence
- contributing indicators
- recommended intervention

## 5. Chatbot
Ask:
- Which students need attention?
- How many are moderate risk?
- What intervention should I use?

## 6. Governance
Show synthetic data, prediction transparency, model traceability and human review.

## 7. Closing
"EngageAI is a decision-support prototype. It does not make academic decisions
automatically. In production, institutional validation, privacy, access control,
monitoring and human approval would be required."
